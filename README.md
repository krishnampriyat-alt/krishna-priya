# Krishna Priya - Digital Marketing Portfolio

A modern, responsive, and professional personal portfolio website designed for a Digital Marketer. Built with HTML5, CSS3, JavaScript, and Bootstrap 5.

## Features
- **Dark Theme:** Clean aesthetic with deep blacks, subtle grays, and a vibrant purple accent.
- **Responsive Design:** Fully mobile-friendly layout utilizing Bootstrap 5 grid and components.
- **Smooth Animations:** Hover effects on cards, buttons, and timeline elements.
- **Sections Included:** Hero, About, Skills, Services, Projects, Education, Contact.
- **Form Validation:** Basic frontend validation for the contact form.

## Technologies Used
- HTML5
- CSS3 (Vanilla CSS with variables)
- JavaScript (ES6)
- Bootstrap 5 (via CDN)
- FontAwesome Icons (via CDN)
- Google Fonts (Outfit)

## How to Run / Preview

Since this project consists of static files (HTML, CSS, JS), no special build tools or servers are required.

1. **Directly in Browser:** 
   Double-click the `index.html` file to open it in your default web browser.

2. **Using VS Code Live Server (Recommended):**
   - Open the project folder in Visual Studio Code.
   - Install the "Live Server" extension by Ritwick Dey.
   - Right-click on `index.html` and select **"Open with Live Server"**.
   - The website will open in your browser and automatically reload when you make changes to the files.

## Customization Guide for Beginners
- **Colors:** You can easily change the theme colors by editing the CSS variables `:root` at the top of `style.css`. Change `--accent-color` to easily switch the vibe from purple to blue or green.
- **Images:** Look for the `<img src="https://placehold.co/...">` tags in `index.html` and replace the `src` attribute with links to your own images or local file paths (e.g., `images/my-profile.jpg`).
- **Content:** The text is structured using basic HTML tags like `<h1>`, `<p>`, and `<h4>`. Simply search for the text you want to change in `index.html` and modify it!
